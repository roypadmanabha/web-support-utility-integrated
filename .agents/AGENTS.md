# Project Rules for Clarivate WSU

## STRICT BRAND COLOR PALETTE
ONLY the following 3 brand colors must be used across all UI elements, pages, buttons, menus, borders, texts, backgrounds, and icons:
1. `#5E33BF` (Clarivate Purple)
2. `#F0F0EB` (Off-white / Warm Light Background)
3. `#000000` (Black)

Do NOT use any other colors anywhere in the application.

## TYPOGRAPHY
Use the custom **Regular Clarivate** typeface (designed by A2-TYPE inspired by Futura, Memphis, and Karnak):
- `font-family: 'Clarivate', 'Clarivate Regular', Futura, 'Memphis', 'Karnak', sans-serif;`
